EXAMPLE 1: Basic Usage (Recommended)
-------------------------------------
from compressor_with_rle import CompressorWithRLE

# Create compressor with RLE enabled (default)
compressor = CompressorWithRLE(verbose=True, use_rle=True)

# Compress file
stats = compressor.compress('input.txt', 'output.bin')
print(f"Compression: {stats['original_size']} -> {stats['compressed_size']} bytes")
print(f"Ratio: {stats['compression_ratio']:.2%}")

# Decompress file (auto-detects format)
compressor.decompress('output.bin', 'recovered.txt')


EXAMPLE 2: Batch Processing
----------------------------
from compressor_with_rle import CompressorWithRLE

files = ['log1.txt', 'log2.txt', 'data.txt']
compressor = CompressorWithRLE(use_rle=True)

for f in files:
    compressor.compress(f, f + '.compressed')


EXAMPLE 3: Direct RLE Usage
----------------------------
from rle import RLE

# Compress runs of identical bytes
data = [ord('A')] * 100 + [ord('B')] * 50
encoded = RLE.encode(data)
decoded = RLE.decode(encoded)

print(f"Original: {len(data)} bytes")
print(f"Encoded: {len(encoded)} bytes")
print(f"Ratio: {len(encoded)/len(data)*100:.1f}%")

================================================================================
ALGORITHM OVERVIEW
================================================================================

RLE Encoding:
  - Single byte: stored as-is
  - Run of 2+ identical bytes: [255, byte, count]
  - Escape byte (255): [255, 255, 1]

Two-Stage Compression:
  1. Run-Length Encode (reduces repetitive patterns)
  2. Adaptive Huffman Encode (generates variable-length codes)

Result:
  Highly effective on repetitive data
  No negative impact on non-repetitive data
  Automatic format detection


================================================================================
WHEN TO USE
================================================================================

USE RLE + Huffman when:
  - Data has repetitive patterns (logs, text)
  - Compression ratio is important
  - File is reasonable size (not pre-compressed)

SKIP RLE when:
  - Data already compressed (ZIP, JPEG, MP3)
  - Data is random or encrypted
  - Speed is more important than size
  - System auto-detects anyway!

================================================================================
FILE FORMAT
================================================================================

Version 2 (RLE + Huffman):
  [8 bits]  Version indicator (2)
  [16 bits] Number of chunks
  [bits]    Huffman-encoded data (from RLE-preprocessed)
  [bits]    Padding

Version 1 (Huffman only) - Original:
  [16 bits] Number of chunks
  [bits]    Huffman-encoded data
  [bits]    Padding

Decompressor automatically detects and handles both!


================================================================================
PERFORMANCE
================================================================================

Encoding:    O(n) time, O(n) space
Decoding:    O(n) time, O(n) space
Huffman:     O(m log m) time where m = RLE output

Typical Results:
  Logs:                99% compression
  Text files:          50-70% compression
  Mixed data:          20-30% compression
  Non-repetitive:      No benefit (skipped)
  Already compressed:  No benefit (skipped)
