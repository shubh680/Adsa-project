================================================================================
                    HOW IT WORKS
================================================================================

COMPRESSION:
  Input → RLE Preprocessing → Huffman Encoding → Compressed Output

DECOMPRESSION:
  Compressed Input → Huffman Decoding → RLE Postprocessing → Output

RLE Algorithm:
  - Single bytes: stored as-is
  - Runs (2+ identical bytes): [255, byte, count]
  - Automatically expands/compresses as needed

Result:
  10,000 identical bytes → [255, byte, 100] → 3 bytes (vs 10,000)
